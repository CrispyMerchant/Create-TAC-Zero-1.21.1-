# Create: TAC Zero

### Bringing Create automation to Timeless and Classics Zero for Minecraft 1.21.1

Create: TAC Zero bridges the gap between **Create** and **Timeless and Classics Zero (TACZ)**, filling the hole left by the absence of an official [Create: Timeless and Classics](https://www.curseforge.com/minecraft/mc-mods/tacz-create) port for 1.21.1.

---

## Requirements

- [Create](https://www.curseforge.com/minecraft/mc-mods/create) for NeoForge 1.21.1
- [[Unofficial] Timeless and Classics Zero (TACZ)](https://modrinth.com/mod/tacz-1.21.1) for NeoForge 1.21.1
